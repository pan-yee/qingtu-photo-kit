# 前端内容安全配置

支持两种独立部署的后端，由 `miniprogram/config/index.js` 的 `contentSecurity.backend` 选择。默认 `'cloud'`，改成 `'http'` 使用自有部署；修改后重新编译，不在运行失败时自动切换。前端不保存任何服务端密钥。

## 微信云开发（默认）

保留配置 `envId: 'photo-d0gn3yvetb21c4a41'`、`functionName: 'contentSecurity'`。选中此模式仅使用 `wx.cloud` 初始化环境、调用云函数和上传临时图片，不调用自有 API。

云函数代码在独立后端项目的 `cloudfunctions/contentSecurity/`；需要完成三个集合、存储访问规则、微信图片检测权限、可信加密回调及异常文件生命周期清理。云模式目前使用异步检测，只有收到明确通过结果才放行。前端改成云模式不代表云端资源已部署或权限已配置；须单独完成真实联调。

## 自有部署

1. 在 `miniprogram/config/index.js` 配置 `contentSecurity.backend: 'http'` 与真实的 `apiBaseUrl`。
2. 微信后台将 API 域名设为 request 合法域名；地址必须使用 HTTPS。
3. 服务端由独立后端项目完成 MySQL、微信 AppSecret、加密回调和临时图片清理配置。
4. 更新隐私保护指引，告知用户图片会临时上传供内容安全检测，按实际运营与数据清理策略披露。
5. 在真机验证登录、图片检测、违规拦截和保存；自建服务同步模式直接获取微信最终结果，异步模式需要可信回调。不能将模拟接口或本地测试通过视为审核通过。

协议及状态语义见[后端接口](./后端接口.md)。前端独立验证执行 `npm run check`，不需要下载后端或安装 Express/MySQL 依赖。

两种后端的部署、密钥和检测状态相互独立。切换配置前确保目标服务可用；缺配置或服务错误时保持拦截。
