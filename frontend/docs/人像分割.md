# 本机人像分割

采用 Google MediaPipe Selfie Segmentation 的 general 模型，来源为固定版本 `@mediapipe/selfie_segmentation@0.1.1675465747` 中的 `selfie_segmentation.tflite`。原模型与转换后模型按 Apache-2.0 分发，完整许可见 `miniprogram/models/LICENSE.txt`，来源及 SHA-256 见同目录 `manifest.json`。

上游：https://github.com/google-ai-edge/mediapipe 。人像分割没有引入原生 WASM、运行时模型下载或远程抠图服务；内容安全检测另行通过微信云开发执行，需要临时上传图片。模型随代码包分发，约 450 KB，不需要 API Key。

## 对原模型的修改

使用 TensorFlow CPU 2.19.1、tf2onnx 1.17.0 转为 ONNX opset 11。将 11 个 HardSwish 展开为标准 Add、Clip 和 Mul；将固定模型最后一个自定义 `Convolution2DTransposeBias` 改写为等价的 Transpose、ConvTranspose（2×2、stride 2、无 padding）及 Transpose。外部输入和输出统一为 NCHW，输入为 float32 RGB / 255，形状 `[1,3,256,256]`；输出为 `[1,1,256,256]` 人像概率。

这些改写不是重新训练。转换脚本只接受已记录 SHA-256 的原模型，检查固定末层形状及替换次数，最后运行 ONNX 图检查。不能直接用于其他版本或其他模型。

## 微信运行链路

`wx.createInferenceSession` 需要基础库 2.30.0 及以上，项目当前固定 3.17.1。按官方 API 声明设置 float32 精度，不启用额外量化和 NPU；每页复用会话，每张照片只推理一次。换底色、尺寸和手动修正复用概率遮罩。输出按双线性放大，按边缘范围和柔化设置生成 alpha，保留原图 RGB。

不支持 API、加载失败或超时，会明确告知用户切换到纯色背景算法；没有识别到清晰人像时要求重新选图。页面卸载会释放会话，避免异步结果回写已销毁页面。

**本次只验证了 ONNX Runtime CPU 和官方 MediaPipe Chromium 实现，没有微信原生推理运行环境。** 算子图检查及输入输出一致性不能替代微信 iOS、Android 真机兼容性测试。上线前须确认设备上实际启用了人像分割，不能把回退算法的成功当成模型成功。

## 可重复验证

小程序与普通单元测试不需要 Python，也没有第三方 npm 依赖。额外效果验证在前端项目根目录执行：

```sh
python3 -m venv /tmp/qingtu-model-tools
/tmp/qingtu-model-tools/bin/pip install -r scripts/requirements-portrait.txt
/tmp/qingtu-model-tools/bin/python scripts/verify-model-conversion.py
/tmp/qingtu-model-tools/bin/python scripts/verify-portrait.py --output /tmp/qingtu-effect
```

效果脚本复用小程序实际的 JavaScript 预处理及后处理，运行代码包内的模型，与旧颜色算法生成对照图。默认使用有公开来源说明的 NASA 测试图片；可用 `--image /path/to/photo.png` 测自己的图片，过程没有网络调用。

重新构建模型（仅开发时需要）：

```sh
npm pack @mediapipe/selfie_segmentation@0.1.1675465747 --pack-destination /tmp
mkdir -p /tmp/qingtu-official-model
tar -xf /tmp/mediapipe-selfie_segmentation-0.1.1675465747.tgz -C /tmp/qingtu-official-model
/tmp/qingtu-model-tools/bin/python scripts/build-portrait-model.py \
  /tmp/qingtu-official-model/package/selfie_segmentation.tflite /tmp/rebuilt-portrait.onnx
/tmp/qingtu-model-tools/bin/python scripts/verify-model-conversion.py --model /tmp/rebuilt-portrait.onnx
```

转换工具生成的节点名可能不同，重建文件不保证逐字节相同；应验证数值结果，再审核替换代码包模型并更新 manifest 校验值，不能仅修改校验值掩盖不匹配。

官方实现的参考遮罩可在安装 Playwright 和 Chromium 后重采集：先把 `tests/fixtures/astronaut.png` 用 Pillow 转为 RGB 并以默认 bicubic 缩放到 256×256 无损 PNG；将该输入及上面解包的 npm 资源交给 `scripts/capture-portrait-reference.cjs`：

```sh
npm install --prefix /tmp/qingtu-reference-tools --no-package-lock playwright
NODE_PATH=/tmp/qingtu-reference-tools/node_modules node scripts/capture-portrait-reference.cjs \
  /tmp/qingtu-official-model/package /tmp/input-256.png /tmp/reference.png
```

默认使用 `/usr/bin/chromium`，可通过 `CHROMIUM_PATH` 指定浏览器可执行文件。参考遮罩只证明转换的一致性，不是人工标注的人像真值。样本范围、实际结果与未验证项见[验证报告](./验证报告.md)。
