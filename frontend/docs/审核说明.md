# 拾格图匣审核提交说明

## 产品定位

拾格图匣是一款本机图片处理小工具。包含 MediaPipe Selfie Segmentation 预训练人像分割模型，通过微信本机推理接口处理用户主动选择的图片；图片加工在本机完成；选图及加工结果需临时上传供微信内容安全检测，不提供生成式 AI、AI 对话、内容社区或付费服务。模型随代码包分发，不从网络下载。

请在微信公众平台按真实功能及所用人像分割能力选择类目。具体类目和资质以当前主体后台及平台审核要求为准，不以隐藏技术实现或改写文案规避要求。

## 版本功能

- 人像换底色：端侧人像分割，支持白、蓝、红、灰或透明底色，以及一寸、二寸、3:4 像素模板。设备不支持模型时明确提示退回纯色背景算法。
- 图片压缩：在本地重新编码并缩小图片。
- 局部擦除：采样笔刷周边像素，修复纯色背景上的小面积文字或图标。
- 图片拼接：将自选图片组合为宫格、横版、竖版或海报。
- 九宫格切图：将一张方图按顺序切成 9 张。

## 隐私说明

使用图片处理功能时，用户需要主动从相册或相机选择图片。图片在本地设备上通过 Canvas 处理。只有用户点击保存且授权相册权限后，结果才会写入用户相册。小程序不读取相册中的其他图片。经用户同意后，选中图片及结果临时上传至运营者服务器并由微信内容安全服务检测；后端通过微信静默登录获取 OpenID 绑定检测任务。检测完成后删除临时图片，异常文件通过服务端定时任务清理。隐私指引需如实写明运营者、服务器所在地、实际清理和备份策略，不收集位置或通讯录。

审核前需要在小程序后台的“用户隐私保护指引”中声明以下用途：

- 选择图片：用于用户主动发起的图片处理。
- 保存到相册：用于保存用户主动确认且检测通过的图片处理结果。
- 临时上传及内容安全检测：说明运营者服务器、微信内容安全服务、使用微信身份标识 OpenID 绑定任务、实际数据保留与清理策略；按真实部署填写。

## 解决 chooseMedia 隐私错误

如果真机出现以下错误：

```text
chooseMedia:fail api scope is not declared in the privacy agreement
```

说明后台隐私指引未声明 `wx.chooseMedia` 对应的信息类型。代码弹窗无法替代后台声明，请使用小程序管理员账号进入：

**小程序管理后台 → 设置 → 服务内容声明 → 用户隐私保护指引**

添加或编辑以下两项：

1. **收集你选中的照片或视频信息**
   - 使用接口：`wx.chooseImage`、`wx.chooseMedia`、`wx.chooseVideo`
   - 用途说明：用于用户主动选择的图片压缩、换底色、局部修复、拼接和切图。
2. **使用你的相册（仅写入）权限**
   - 使用接口：`wx.saveImageToPhotosAlbum`
   - 用途说明：仅在用户点击保存后，将处理结果写入用户相册。

保存并提交隐私指引更新。更新通过后再重新编译小程序。`requiredPrivateInfos` 只用于地理位置类隐私接口，不需要也不应把 `chooseMedia` 添加进去。

## 提交时可直接使用的功能说明

> 本版本提供图片尺寸调整、压缩、底色替换、局部修复、拼接和切分。图片加工在本机完成，原始素材和加工结果经用户同意后由服务端调用微信图片内容安全 API 检测；只有收到可信回调并明确通过，才允许预览和保存。违规内容仅提示“所发布内容含违规信息”，检测未完成或失败时不放行。

仅在完成[自有服务器部署与真实联调](./后端接口.md)后使用上述模板；当前代码和本地测试不代表服务器已部署或审核已通过。

## 内容安全

平台已明确要求证件照场景接入内容安全。本次已在公共链路接入 `security.mediaCheckAsync`，覆盖原始选图、加工结果、预览和相册保存，不以“不存在发布场景”为由跳过。尚无用户输入文本，因此不以检测固定文案虚构 `msgSecCheck` 调用。机制与未完成配置见[内容安全说明](./内容安全说明.md)。

## 审核前自查

- 如实声明端侧预训练人像分割能力；介绍和实际代码一致，不宣传未实现的生成式能力。
- 正式 AppID、类目、服务内容与实际页面保持一致。
- 隐私保护指引包含选图、保存相册、临时上传和微信内容安全检测用途，并能从授权弹窗正常打开。
- 真实图片调用、可信回调、违规拦截、失败不放行及临时文件清理均已联调。
- 未授权时必须先完成隐私授权；拒绝后不调用选图或保存接口，并允许继续浏览。
- 激励广告保持关闭，待小程序审核通过并完成流量主资质后再配置。
- 使用本人原创、无敏感内容的测试照片提交审核。
- 真机检查授权拒绝、重新授权和保存失败提示。
