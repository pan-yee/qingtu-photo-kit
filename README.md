# 轻图盒

一个本地优先的微信小程序图片工具箱，覆盖图片处理类小程序最常见的高频需求：

- 证件照智能换底色（白、蓝、红、灰、透明）
- 图片压缩，支持三档尺寸与质量
- 纯色背景局部擦除（适合文字、小面积水印）
- 多图拼接，支持宫格、横版、竖版和海报模板
- 九宫格切图，一次生成 9 张可直接发布的小图

所有图片默认只在设备本地处理，不上传服务器。项目不依赖第三方 npm 包，下载后可直接用微信开发者工具导入。

## 快速开始

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 打开工具，选择“导入项目”，目录选择本仓库根目录。
3. 测试可直接使用 `project.config.json` 中的游客 AppID；真机预览、上传和保存相册前，请换成自己的小程序 AppID。
4. 在管理后台补充小程序名称、类目、隐私保护指引，并按实际页面截图提交审核。

## 功能边界

“智能换底色”使用边缘采样、颜色聚类和连通区域分割，适合拍摄于白墙、蓝布等纯色背景的人像。头发细丝、复杂背景和低对比服装可能需要替换为专业 AI 抠图服务。

“局部擦除”通过采样笔刷周边像素进行平坦区域修复，适合纯色证件、表格或海报上的小水印。它不能还原大面积遮挡下的未知内容。不要用此工具移除他人作品中的版权标识，也不得用于伪造证件或规避版权保护。

## 目录结构

```text
miniprogram/
  pages/
    home/       首页
    cutout/     证件照换底色
    compress/   图片压缩
    erase/      局部擦除
    collage/    图片拼接
    grid/       九宫格切图
  utils/        图片算法、画布和媒体工具
  config/       广告与可选 AI 服务配置
tests/          核心算法单元测试
scripts/        项目静态校验
```

## 商业化配置

打开 `miniprogram/config/index.js`：

```js
enableRewardedAds: true,
rewardedVideoAdUnitId: 'adunit-你的广告位ID'
```

保存高清图片前会调用激励视频。未配置广告位时自动直接允许导出，便于开发调试。上线前还需在小程序后台开通流量主并审核广告位。

若接入云端 AI 抠图，建议新增云函数或 HTTPS 服务，让密钥只保存在服务端；再把返回的透明 PNG 临时地址传给换底页面。不要把服务端密钥写进小程序代码。

## 发布前检查

- 将 `project.config.json` 的 `appid` 替换为正式 AppID。
- 在“用户隐私保护指引”中声明选择图片、保存到相册的用途。
- 配好正式域名和内容安全策略（如接入云端 AI）。
- 以真机检查相册授权拒绝后的引导流程。
- 使用自己的原创图片测试，不收集、不上传未经用户许可的素材。
- 执行 `npm test` 和 `npm run validate`。
