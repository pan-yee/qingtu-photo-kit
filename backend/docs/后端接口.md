# 前后端接口

前端与后端分别部署，不通过相对路径引用对方代码。前端配置 `miniprogram/config/index.js` 的 `contentSecurity.backend: 'http'` 和 `apiBaseUrl`；服务端 `PUBLIC_BASE_URL` 应指向同一 HTTPS 基址。默认地址为 `https://www.ai-dreams.xyz/qingtu-api`，微信后台需将域名配置为 request 合法域名。

| 方法及路径（相对于 API 基址） | 请求 | 结果 |
| --- | --- | --- |
| `GET /health` | 无 | 就绪时 HTTP 200、`{ok:true}`；数据库或清理服务异常时 503 |
| `POST /session` | JSON `{code}`，code 来自 `wx.login` | `{ok:true,token,expiresIn:3600}` |
| `POST /jobs` | JSON `{}`，Bearer JWT | 分配任务：`jobId`、`uploadPath`、`status:reserved`、`expiresAt` |
| `POST /jobs/:id/image` | `application/octet-stream` 原始 JPG/PNG，最多 10 MiB，Bearer JWT | `{ok:true,fileId}` |
| `POST /jobs/:id/submit` | JSON `{fileId}`，Bearer JWT | 当前状态、`jobId`、实际图片 `sha1`、`expiresAt`；异步模式为 `pending`，同步模式可直接返回最终结果 |
| `GET /jobs/:id/status` | Bearer JWT | 归属当前用户的检测状态及图片摘要 |
| `DELETE /jobs/:id/image` | Bearer JWT | 清理上传临时文件 |
| `GET/POST /wechat/callback` | 微信签名挑战或加密事件 | 可信事件改变检测结果；不由客户端提交通过状态 |
| `GET /media/:name` | 服务端签名与有效期参数 | 仅供微信抓取检测副本，不向前端返回图片签名 URL |

JWT 仅驻留客户端内存，不把 OpenID 当成客户端可以自行指定的身份。服务端 AppSecret、JWT 密钥、图片签名密钥、消息 Token、EncodingAESKey 和数据库密码只保存在后端；前端配置只能包含公开 API 基址及 AppID。

只有实际文件摘要匹配、未过期且状态明确为 `pass` 才允许使用结果。`pending`、`reserved`、`submitting`、`review`、`error`、`expired`、未知状态和网络错误不能放行；`reject` 提示“所发布内容含违规信息”。检测任务受理不代表通过。

前端在选图、生成结果、预览及保存入口执行公共校验，覆盖全部工具。后端支持同步 `img_sec_check` 直接取得最终结果，也支持异步 `media_check_async` 获得 traceId 并验证加密回调后更新结果。HTTP 集成测试模拟微信与存储，不能替代真实微信后台和 MySQL 联调。
