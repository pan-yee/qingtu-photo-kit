# 本次审核拒绝与修复机制

平台反馈已明确指出【证件照】功能存在信息安全风险，要求接入内容安全 API，并在所有可能的内容发布场景生效。此前“不提供公开发布、图片仅本地处理”的解释不足以满足这次审核要求。

已实现的图片检测接口是 **`security.mediaCheckAsync`（version 2、图片类型、scene 2）**。审核链接中的 `msgSecCheck` 用于文本；本项目没有用户输入文本，不能仅检测固定文案来冒充图片内容安全校验。

## 已实现

- 选图先校验素材，加工后校验结果，预览与保存前再次核对文件摘要与短期通过状态；覆盖证件照、压缩、擦除、拼接和九宫格。
- 九宫格先核验全部 9 张，再播放激励视频及保存；普通保存也先检测，广告不充当安全校验。
- 自有后端通过微信登录得到真实 OpenID，以独立 JWT 验证任务归属；不接受客户端指定他人身份、文件路径或检测结果。
- 服务端复制不可由客户端修改的图片副本送检，以实际文件摘要绑定检测任务。
- 异步接口返回 traceId 只代表受理，必须等待微信签名加密回调的明确 `pass`。回调支持提前到达、去重和过期拦截。
- 回调验签、解密并核对接收 AppID；客户端传来的 `pass` 或未经验证的明文不被接受。
- `review`、违规、未知状态、服务错误、缺少配置、超时和文件被替换都不放行。违规提示统一为 **“所发布内容含违规信息”**，不向用户输出违规类别和命中细节。
- 上传前征求用户同意；首页、证件照和隐私说明已删除“不上传”的错误承诺。图片检测后删除；自有后端每分钟清理超过 10 分钟的异常残留，清理失败时暂停新图片任务。

## 当前状态

默认配置已改为 `backend: 'http'`，请求 `https://www.ai-dreams.xyz/qingtu-api` 的独立 Express / MySQL 服务，不调用腾讯云函数、云数据库或云存储。旧云函数保留为备用，没有自动删除云资源。自有服务器代码和本地 HTTP 集成测试已完成；实际部署进展及未验证项见[验证报告](./验证报告.md)。只有可信回调明确通过后才放行，缺配置或服务不可用时继续拦截。

请按[自有服务器部署说明](../server/README.md)配置服务器环境、独立数据库、Nginx、微信合法域名和加密回调。不要在小程序前端写入 AppSecret、access_token、消息 Token 或 AESKey，也不要在聊天中发送这些值。

`npm run check` 是本地代码和行为验证，不是微信官方安全检查。只有部署、真机联调、收到可信结果并重新通过平台审核后，才能报告审核问题已解决。
