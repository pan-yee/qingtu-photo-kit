# 内容安全审核说明

## 小程序内不存在内容发布场景

拾格图匣不提供用户生成内容的公开展示、发布、评论、转发、投稿或社区功能。用户选中的图片只在自己的设备上通过 Canvas 处理，处理结果由用户主动保存到本人相册。

所有页面均没有以下能力：

- 内容发布按钮或上传入口
- 评论、点赞、收藏、分享到小程序内
- 用户内容广场、相册、动态或投稿列表
- 图片上云保存、生成可公开访问的链接

因此，`security.msgSecCheck` 与 `security.imgSecCheck` 没有小程序内可触发的发布场景。若平台仍要求接入，请将审核标准中判定为“发布”的具体页面和操作路径反馈给我们，我们会按对应场景补充内容安全校验。

## 可直接提交给审核员的说明

> 本小程序为纯本地图片处理工具，不包含用户内容的发布、上传、评论、分享或社区展示功能。用户图片仅在本机处理，处理后由用户主动保存到自己的相册。小程序未提供需要调用内容安全接口的发布场景。

## 代码侧已完成的配合调整

- 首页与九宫格页面不再出现“发布”“发朋友圈”“上传”“投稿”等字样。
- 页面只提示“保存到相册”，不承诺把内容发布到任何平台。
- 保存结果调用系统相册能力，而不是微信内容发布接口。
