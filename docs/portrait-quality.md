# 证件照质量升级：第一轮

分支：`feat/portrait-quality`。基线：`336d041`。

## 本轮修改

- ECS 配置保持启用。前端裁切遮罩直接采样到实际渲染尺寸（当前 900×1200），移除固定 450×600 的中间网格，避免先降采样再放大造成细发丝透明度丢失。测试桥同步使用相同尺寸。
- 去残色从八个方向的局部可靠背景估计颜色，按距离加权。任一颜色通道标准差超过 24 时放弃校色，降低复杂背景中取单侧背景造成错误校色的风险。仍只处理半透明边缘，不改动不透明脸部、衣服或原图；没有背景证据时保留颜色。
- 保留既有模型、构图比例、上传授权和审核流程。

## 验证与成本

`npm --prefix frontend run check`：192 项测试、页面语法/事件及本地安全检查通过。新增输出网格细线保真、对角背景去残色、复杂背景不误校色回归。

合成实验：900×1200 遮罩，仅第 451 列 alpha=0.75，其余为 0，使用完整同尺寸裁切、默认范围与渲染。基线使用 `336d041` 的 framing 模块；两版都经过真实前端 alpha 渲染代码。

| 指标 | 基线 | 修改后 |
| --- | --- | --- |
| 渲染后细线 alpha（0–255） | 72 | 191 |
| 相邻像素 alpha（应为 0） | 72 | 0 |
| 全图 alpha 平均绝对误差（0–1） | 0.00104248 | 0.00000109 |
| Float32 遮罩大小 | 1,080,000 字节 | 4,320,000 字节 |

这仅证明避免了中间网格造成的细节丢失，不能证明 MODNet 能预测出原图中全部细发丝。一次本机采样与渲染测得约 59→76 ms，不代表手机耗时；需真机检查内存、涂抹和连续换底响应。

全仓 `npm run check` 前端通过、后端语法校验通过，但后端测试因环境未安装 `express` 中断。此次没有修改后端。

## 尚需验证与后续

环境没有 MODNet 权重和历史照片，未进行真实人像推理、蓝白底人工验收或竞品同图对比，未部署 ECS 或发布小程序。去残色的局部估计在纹理背景下仍可能不准确，本轮不声称整图观感或竞品差距已有量化改善。

后续固定真实照片集合，对比原图、当前版、本分支和竞品结果，分别评估发丝完整、白边/残色、衣服完整及构图。模型替换须先比较权重许可、推理资源、耗时和同图质量；本轮不凭模型名称直接替换。构图规格和肤色/光照校正也尚未实施，需要对应样本验收。

让本轮修改生效需重新编译并发布前端小程序；无需为这两处修改重建 worker。
