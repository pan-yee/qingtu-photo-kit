# 拾格图匣审核提交说明

## 产品定位

拾格图匣是一款离线图片处理小工具。全部处理都在用户设备本地完成，不上传图片，不提供 AI 生成、AI 对话、内容社区、付费服务或云端处理能力。

建议在微信公众平台按真实功能选择与“图片处理”“效率工具”对应的可用类目。具体可选类目以个人主体后台上实际展示的选项为准，不要选择或申报 AI 类目。

## 版本功能

- 人像换底色：通过边缘颜色分析，为纯色背景人像更换白、蓝、红、灰或透明底色。
- 图片压缩：在本地重新编码并缩小图片。
- 局部擦除：采样笔刷周边像素，修复纯色背景上的小面积文字或图标。
- 图片拼接：将自选图片组合为宫格、横版、竖版或海报。
- 九宫格切图：将一张方图按顺序切成 9 张。

## 隐私说明

使用图片处理功能时，用户需要主动从相册或相机选择图片。图片在本地设备上通过 Canvas 处理。只有用户点击保存且授权相册权限后，结果才会写入用户相册。小程序不读取相册中的其他图片，不上传图片，不收集身份、位置、通讯录或其他个人信息。

审核前需要在小程序后台的“用户隐私保护指引”中声明以下用途：

- 选择图片：用于用户主动发起的图片处理。
- 保存到相册：用于保存用户主动确认的图片处理结果。

## 解决 chooseMedia 隐私错误

如果真机出现以下错误：

```text
chooseMedia:fail api scope is not declared in the privacy agreement
```

说明后台隐私指引未声明 `wx.chooseMedia` 对应的信息类型。代码弹窗无法替代后台声明，请使用小程序管理员账号进入：

**小程序管理后台 → 设置 → 服务内容声明 → 用户隐私保护指引**

添加或编辑以下两项：

1. **收集你选中的照片或视频信息**
   - 使用接口：`wx.chooseImage`、`wx.chooseMedia`、`wx.chooseVideo`
   - 用途说明：用于用户主动选择的图片压缩、换底色、局部修复、拼接和切图。
2. **使用你的相册（仅写入）权限**
   - 使用接口：`wx.saveImageToPhotosAlbum`
   - 用途说明：仅在用户点击保存后，将处理结果写入用户相册。

保存并提交隐私指引更新。更新通过后再重新编译小程序。`requiredPrivateInfos` 只用于地理位置类隐私接口，不需要也不应把 `chooseMedia` 添加进去。

## 提交时可直接使用的功能说明

> 本版本仅提供本地图片尺寸调整、压缩、底色替换、局部修复、图片拼接和图片切分功能。所有素材由用户主动选择，处理过程在本地完成，不上传服务器，不提供 AI 生成或 AI 对话能力。

## 内容安全

小程序内不提供发布、评论、分享、投稿或社区功能，也没有公开的用户内容页面，因此不存在需要调用 `security.msgSecCheck` 或 `security.imgSecCheck` 的发布场景。界面已移除“发布”“发朋友圈”等措辞，统一描述为“保存到相册”。审核回复模板见[内容安全说明](./内容安全说明.md)。

## 审核前自查

- 首页、按钮和介绍中不出现 AI 生成、AI 对话、AI 抠图等无法匹配个人主体类目的表述。
- 正式 AppID、类目、服务内容与实际页面保持一致。
- 隐私保护指引包含选图和保存相册用途，并能从授权弹窗正常打开。
- 首次选择图片或保存图片前会出现隐私授权弹窗。
- 激励广告保持关闭，待小程序审核通过并完成流量主资质后再配置。
- 使用本人原创、无敏感内容的测试照片提交审核。
- 真机检查授权拒绝、重新授权和保存失败提示。
