# 小程序名称与简介

## 推荐名称

主名称：

```text
轻图盒图片处理工具
```

名称由品牌词“轻图盒”和核心搜索词“图片处理工具”组成。用户搜索“图片处理”“图片压缩”“图片拼接”时，名称与服务简介能够形成一致的关键词匹配，同时没有使用 AI、去水印或其他容易引发类目和版权审核的关键词。

如果后台提示名称已被占用，可按优先级尝试：

1. `轻图图片压缩拼接助手`
2. `轻图盒图片压缩拼接`
3. `随手图片处理工具箱`
4. `轻松图片拼接切图`

落选名称仅用于解决重名问题，不建议同时堆叠过多关键词。
