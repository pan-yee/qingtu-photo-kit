# 互联网随机 100 张照片验证（2026-11-13）

来源：[P3M 项目](https://github.com/JizhiziLi/P3M) / [公开下载镜像](https://huggingface.co/datasets/nobg/P3M-10K)，P3M-500-NP。使用 `random.Random(20261113).sample(range(500),100)` 在推理前一次选样，不按生成结果替换照片。原照片版权属于权利人，仅用于本地软件验证。部分随机抽中照片曾出现在此前验证中，因此不是完全独立留出集。

100 张全部下载，保留原始下载字节 SHA256；为限制磁盘占用，本地照片及标注等比缩小到最长边 1600。来源见 [清单](validation/portrait100-sources.json)，逐张结果见 [报告](validation/portrait100-report.json)。未向 ECS、微信或收费服务上传这些测试照片。

## 实际生成结果

固定线上同版本 `e15b810` 的 worker 为基准，和修改后的真实 worker 分别处理全部 100 张；成功样本使用实际前端构图及透明度处理代码生成蓝底、白底，不伪造模型响应。

- 修改前：32 张生成，68 张拒绝。
- 修改后：31 张生成，69 张拒绝；其中 51 张未检测到可用人脸、4 张主要多人、4 张姿态不适合、10 张头部不完整。
- 新增拒绝 `162`：目视原图确认发髻在照片顶边被截断；旧版仍输出截平发髻，修复后停止输出。成功数量减少是输入拦截修复，不是背景清理分数提升。
- 另外单独复测已知 `215`，旧版输出截平发髻，新版拒绝。该指定案例不混入随机 100 张计数。

## 代码优化

- 顶边检查覆盖局部推理区域，不再只检查原图顶边。
- 将头部顶边占据比例阈值由 30% 收紧到 15%，覆盖较窄的截断发髻。
- 局部区域触及头部时，最多使用完整原图重试一次；原图本身仍缺头则返回明确错误，不生成或补画头部。
- 模型输出增加形状检查，保留有限数值、脸部遮罩和模型哈希检查。
- 下载工具支持数量及固定随机种子；新增完整 worker 验证和逐张结果页脚本。生成的像素缓冲随用随清理，原图、标注、JPEG 和报告保留。

14 项 Python worker 测试通过，包含局部顶边、较窄截断发髻、完整原图重试及最多两次推理检查；Python 语法与 Git 空白检查通过。前端算法未更改。对 `162`、`215` 做了针对性的视觉核对，没有声称对其余照片进行了独立盲评或证件照受理认证。

本轮优化的是截头漏检与安全构图，不代表复杂背景已清理完美。发丝残色、遮挡、表情、服装及原图清晰度仍需人工核对；不能把随机 100 张描述成 100 张成功证件照。

本轮尚未推送、部署 ECS 或上传小程序；不会覆盖已经发布的 `e15b810`。

复现：安装 `backend/matting/requirements.txt` 并设置固定哈希的 `MODNET_MODEL_PATH`。执行 `scripts/evaluate-background30.py --count 100 --seed 20261113 --output <目录>` 下载素材。将 `e15b810` 的 worker 源码及 YuNet 模型放入独立目录，分别执行 `scripts/verify-portrait100.py --input <目录> --worker <旧worker目录> --name before` 和 `--worker backend/matting --name after`，最后运行 `scripts/build-portrait100-review.py <目录>`。
