# 图片工具优化（2026-11-11）

本次优化图片压缩、图片拼接、九宫格切图和局部擦除。

## 使用变化

- 压缩增加自动 / JPG / PNG 格式。PNG 保留透明度，明确转 JPG 时铺白底。原生接口不支持尺寸参数或没有遵守尺寸限制时，使用等比画布编码；小图不放大。自动模式遇到更大的重编码文件，会在原图已符合尺寸限制时保留原图。显示实际输出尺寸和大小，未知大小不显示虚假的节省比例。
- 拼接默认完整显示，可选择铺满裁切。缩略图支持前移、后移，调整图片或版式后清空旧结果。生成期间改变输入或离开页面，旧任务不会覆盖新结果。修复基础库默认按钮宽度导致的模板溢出。
- 九宫格默认完整显示并留白，也可铺满裁切和调整裁切位置。预览显示 1–9 编号，生成显示进度，切片复用一张小画布。批次保存中断后继续保存剩余图片，不重复播放同一批次已完成的广告。重试仍先校验整个批次，任何一张未通过都不写入相册。
- 擦除保留原图比例，最长边仍为 900 像素，不再强制正方形。笔刷按屏幕直径映射，横纵坐标分别换算；快速移动时补充采样。增加重做和按住看原图。撤销最多保存 4 个笔画的快照，历史到达上限时仍正确判断图片是否有修改；重置可恢复原图。处理和对比期间禁止涂抹或保存。
- 公共单图保存增加互斥，防止重复点击产生重复广告或相册写入；失败后可再次尝试。
